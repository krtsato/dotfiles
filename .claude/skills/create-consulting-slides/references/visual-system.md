# Visual System

## 基本原則

- 16:9を既定とし、ユーザー指定または既存テンプレートを優先する
- 先にグレー階調で情報階層を作り、最後に意味のある強調色を加える
- 一枚の強調色は原則一色、必要な場合でも二色までにする
- 強調は色だけに依存せず、サイズ、太字、位置、余白を併用する
- 画面全体を同じ大きさの角丸カードで埋めない
- 表の罫線を減らし、列見出し、帯、余白で比較方向を示す
- 出典と注記は小さくしても、省略しない

## スライドの五層

1. **Section label**：章または資料内の現在地
2. **Title**：このページの結論
3. **Lead**：結論の理由または読み方
4. **Body**：証拠、比較、工程、数値
5. **Source and page**：出典、基準日、ページ番号

## レイアウトの選択

| 目的 | 適した型 | 避けること |
| --- | --- | --- |
| 因果や流れを示す | 左から右のプロセス、スイムレーン | 円環にして開始点を失う |
| 複数案を選ぶ | 同じ軸の比較表、2×2 | 案ごとに異なる評価語を使う |
| 数値差を示す | 棒、折れ線、ウォーターフォール | 比較不能な単位を同じ軸へ載せる |
| 定義や責任を分ける | 二列表、境界図 | 長文段落を左右へ並べる |
| 時間と担当を示す | ロードマップ、日程表 | 期限のないToDo一覧 |
| 章を切り替える | 中扉 | 本文と同じ密度にする |

## 文字量の判断

- 一枚一メッセージを守る
- 本文段落より、行単位で比較できる表現を優先する
- 小さな文字へ縮める前に、ページ分割、付録移動、図表化を検討する
- 行見出しだけで意味が通らない表は、文章の主語と述語を補う
- スライド内の用語説明が本文より長い場合は、定義ページまたは付録を作る

## 色の意味

配色はブランド指定を優先する。指定がなければ、ベースは暖色をわずかに含む薄い
グレー、本文はチャコールとする。アクセントは意味を固定する。

| 意味 | 色の役割 |
| --- | --- |
| 採用、確認済み、改善 | 落ち着いたティールまたは青緑 |
| 優先、期限、次の行動 | オーカーまたは橙 |
| リスク、未確認、停止条件 | 落ち着いた赤 |

同じ赤を、リスクと単なる装飾の両方には使わない。

## 全体確認

contact sheetでは次を見る。

- タイトルの長さと位置が揃っているか
- 中扉が章の境界として識別できるか
- 特定ページだけ過密または空疎でないか
- 強調色が資料全体で過剰に増えていないか
- 表紙、アジェンダ、結論、次の行動が離れすぎていないか

原寸画像では次を見る。

- 文字切れ、重なり、改行位置
- 表の列幅、数字の桁、単位、注記
- 色のコントラストと出典の可読性
- 図形とテキストの整列
