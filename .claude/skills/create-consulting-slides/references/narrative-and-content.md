# Narrative and Content

## 抽象から具体への順序

各章は、次の順序で読み手の理解を深める。

1. **結論**：何を言いたいか
2. **理由**：なぜその結論になるか
3. **証拠**：どの事実、数値、事例が支えるか
4. **条件**：どの範囲なら成立し、何が未確認か
5. **行動**：誰が、いつ、何をするか

「市場性が高い」「運用を強化する」「収益化できる」のような抽象語だけで終えない。
何が、誰に対して、いつまでに、どの指標で変わるかを追記する。

## 5W1Hと判断情報

| 要素 | スライドで答える問い | 具体化の例 |
| --- | --- | --- |
| Who | 誰が実行し、誰が利用するか | 事業責任者、首都圏の新規顧客 |
| What | 何を提供・比較・決定するか | 三案を同じ費用と期間で比較 |
| When | いつ実行し、いつ判断するか | 承認後14日、14日目に判定 |
| Where | どの市場、地域、チャネルか | 日本語圏、既存顧客向けメール |
| Why | なぜ今、なぜその案か | 解約率上昇が利益を毀損しているため |
| How | どの手順、導線、体制か | 調査、試作、公開、計測の順 |
| How much | いくら、何時間、何件か | 15万円、40時間、顧客10社 |

すべてを毎ページへ載せる必要はない。意思決定に影響する要素だけを明示する。

## 主語と術語

- 主語が組織、顧客、システム、指標のどれかを明示する
- 「対応する」ではなく、担当者と完了状態を書く
- 売上、GMV、発生報酬、確定報酬、利益を区別する
- 予測、試算、目標、実績を同じ表で混ぜない
- 初出の略語は正式名称を併記する
- 同じ概念にはデッキ全体で同じ語を使う

## 証拠強度

| レベル | 証拠 | 使い方 |
| --- | --- | --- |
| A | 法令、公式統計、一次データ、契約・規約 | 主要判断の直接根拠にできる |
| B | 当事者の実績開示、監査済み企業資料 | 条件と指標定義を添えて使う |
| C | 第三者事例、販売者掲載、専門家解説 | 仮説形成や補助証拠として使う |
| D | 検索要約、出典不明の投稿、伝聞 | 結論の根拠にせず、追加調査へ回す |

公開値には、運営主体、期間、指標、母数、費用控除の有無、確認日を付ける。比較条件が
異なる数値は棒グラフへせず、条件付きの事例表として並べる。

## 章とページの接続

悪い接続:

> 市場の説明の次に、説明なく実行計画が始まる。

良い接続:

> 市場比較から三条件が分かった。次章では、その三条件で候補案を採点する。

中扉は装飾ページではない。次の章が答える問い、直前の章から引き継ぐ事実、章の結論を
短く示す。

## タイトルの変換例

| 抽象・名詞タイトル | 結論タイトル |
| --- | --- |
| 市場調査結果 | 市場は拡大しているが、利益は二社に集中する |
| 施策案 | 既存顧客への再提案を第一施策にする |
| 今後の対応 | 営業責任者が14日以内に10社へ試す |
| リスク | 法令確認が終わるまで公開を開始しない |

タイトルだけを順番に読んでも、資料の論理が通る状態を目指す。
