# 現在時刻の出力

現在の時刻や日付を尋ねられたとき、推測や文脈からの逆算で答えてはいけない。実行環境のシステムクロックは信頼できる唯一の情報源なので、必ず同梱スクリプトを実行して実際の値を取得する。

## 使い方

`scripts/current_time.py` を実行する。引数なしで実行すると、日本標準時 (JST) で読みやすい形式の現在時刻を出力する。

```bash
python3 scripts/current_time.py
# => 2026-06-22 15:30:05 JST
```

## オプション

タイムゾーンや出力書式を変えたいときは引数を渡す。

- `--tz <IANA名>` : タイムゾーンを指定 (例: `UTC`, `America/New_York`)。既定は `Asia/Tokyo`。
- `--format <名前 または strftime文字列>` : 出力書式を指定。既定は `default`。

利用できる書式プリセット:

| プリセット | 出力例 |
|---|---|
| `default` | `2026-06-22 15:30:05 JST` |
| `iso` | `2026-06-22T15:30:05+0900` |
| `ja` | `2026年06月22日 15時30分05秒` |
| `date` | `2026-06-22` |
| `time` | `15:30:05` |

プリセット名に当てはまらない値は strftime 文字列としてそのまま使われるので、`--format "%H:%M"` のような自由な書式も指定できる。

```bash
# ISO 8601 形式
python3 scripts/current_time.py --format iso

# UTC の日付だけ
python3 scripts/current_time.py --tz UTC --format date

# 任意の書式
python3 scripts/current_time.py --format "%Y/%m/%d (%a) %H:%M"
```

## 出力の扱い方

スクリプトは結果を標準出力に1行で返す。その値をユーザーへの回答にそのまま使うか、求められた文脈 (ログ行、ファイル名など) に埋め込む。ユーザーが書式やタイムゾーンを明示していない場合は、`default` (JST・読みやすい形式) で答えれば十分なことが多い。
