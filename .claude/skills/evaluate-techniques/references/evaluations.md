# 評価シナリオ

この skill が**起動すべき場面**と**起動してはいけない場面**、そして
**手順どおりに動くか**を確かめる項目。

## 起動すべき（positive trigger）

| # | 利用者の言い方 | 期待する動き |
| --- | --- | --- |
| P1 | 「RSI を直したので影響を測って」 | 修正前後の実行ファイルを作り、同じ cache と種で両方走らせ、`compare.py` で突き合わせる |
| P2 | 「合流で測って」「複数の技法を掛け合わせたら？」 | `-confluence-state` と `-levels 4,5,6,7,8,9,10` で走らせ、単調性と水準ごとの表を出す |
| P3 | 「技法にエッジはある？」 | 既定の設定で走らせ、判定の内訳と上回った技法の一覧を出す |
| P4 | 「前と比べてどう変わった？」 | 2 つの結果 JSON を `compare.py` に渡す |
| P5 | 「合流で差が出なかったので終わりでいい？」 | **終わらせない。** 全水準で試行数が同じなら関門が効いていないので、水準を上げて測り直す |

## 起動してはいけない（negative trigger）

| # | 利用者の言い方 | なぜ違うか | 正しい行き先 |
| --- | --- | --- | --- |
| N1 | 「買い候補を 30 個出して」 | 銘柄の絞り込みであって技法の評価ではない | `screen-margin-improving-stocks` |
| N2 | 「この技法で発注して」 | この skill は読むだけで発注しない | `trade-moomoo`（既定は模擬） |
| N3 | 「台帳に溜まった判断を集計して」 | 前向き台帳の集計は別の道具 | MCP ツール `tradingview:tradingview_ledger_report` |
| N4 | 「新しい技法ノートを書いて」 | 知識層の起案であって評価ではない | `mcp-invest-knowledge` の著述 workflow |
| N5 | 「Go の版を上げて」 | 版上げは別の手順 | `upgrade-runtimes` |
| N6 | 「この技法は儲かる？」 | **この skill は儲かるかを測らない。** 測るのは「でたらめな売買より良いか」まで | 言い換えて P3 として扱う |

## 動作確認（functional test）

### 1. 正しい出力が出るか（valid outputs）

| 確かめること | 期待 |
| --- | --- |
| `compare.py` を正常な 2 ファイルに掛ける | 判定の内訳・変化した対象・件数の 3 節が出て、終了コード 0 |
| 判定の内訳が 4 語すべてを並べる | `outperformed_matched_null` / `not_significant` / `insufficient_power` / `not_evaluable` |
| 変化した行に p 値と q 値が並ぶ | 片方だけにならない |

### 2. 外部への問い合わせが通るか（external calls）

| 確かめること | 期待 |
| --- | --- |
| `-cache-dir` が空の状態で走らせる | 価格を取得し、2 回目以降は `cached` と記録される |
| 同じ cache で 2 回走らせる | 同じ結果になる（再現する） |

### 3. 異常時に止まるか（error handling）

**すべて終了コード 1 で落ちること。** 「差が無い」と「測れていない」を混ぜないため。

| 壊し方 | 期待するエラー |
| --- | --- |
| 結果 JSON から `total_trades` を消す | 「項目 ['total_trades'] がありません」＋読める項目の一覧 |
| 片方の JSON から技法を 4 件削る | 「比べる対象が揃っていません。前だけ: [...]」 |
| 全水準の試行数が同じ合流結果を渡す | 「水準を上げても試行数が減っていません — k=1(76) = k=2(76)...」 |
| `-confluence-state` なしの結果に `confluence` を指定 | 「合意の結果がありません」 |

### 4. 境界（edge cases）

| 場面 | 期待 |
| --- | --- |
| 技法が 0 件の結果 | 「技法別の結果がありません」で落ちる |
| 判定が 1 件も変わらない | 「試行数も判定も、1 件も変わっていない」と明記する（黙らない） |
| 水準が 1 つだけ | 隣との比較が無いので関門の検査は通る（減少を確かめられないことを報告に書く） |
| 存在しないファイルを渡す | 「を開けません」で落ちる |
