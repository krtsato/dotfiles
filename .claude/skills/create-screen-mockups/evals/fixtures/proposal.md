# 現場点検アプリ 提案書（評価用の架空データ）

> このファイルは create-screen-mockups スキル自体を試験するための架空の入力です。実際の案件では使いません。案件では、その案件の要求資料・要件書・確認事項を使います。

このスキルの評価専用の要求資料です。要件書（requirements.md）はこの提案書から作られています。会社名・人名はすべて架空です。

| # | 機能 | 内容 |
| --- | --- | --- |
| 1 | ログイン | 点検員が ID とパスワードでログインする |
| 2 | 今日の点検一覧 | 予定日が今日の点検を、時刻・点検名・拠点名・状態とともに表示する |
| 3 | 点検の詳細 | 点検名・拠点名・住所・連絡先・状態を表示する |
| 4 | 状態の変更 | 未着手・作業中・完了を切り替える |
| 5 | 写真の登録 | 撮影した写真を複数まとめて登録し、成否を示す |
| 6 | チェックリスト | 点検項目を確認済みにし、確認済みの数を示す |

対象外: 一覧の並び替え、地図・電話との連携、集計・ダッシュボード、オフラインでの登録。
