# 現場点検アプリ 要件書（評価用の架空データ）

このスキルの評価専用の入力です。会社名・人名・住所はすべて架空です。
ブランド色は企業サイトの代わりに `#2E7D6B` を使います。

| 要件 No. | 機能 | 要件 | 表示する情報 |
| --- | --- | --- | --- |
| 001 | ログイン | 点検員がログインできる | ID、パスワード |
| 002 | 今日の点検一覧 | 予定日が今日の点検を表示する | 時刻、点検名、拠点名、状態 |
| 003 | 点検の詳細 | 点検の内容を確認できる | 点検名、拠点名、住所、連絡先、状態 |
| 004 | 状態の変更 | 未着手・作業中・完了を切り替える | 現在の状態 |
| 005 | 写真の登録 | 撮影した写真を複数まとめて登録する | 写真、登録の成否 |
| 006 | チェックリスト | 点検項目を確認済みにする | 項目名、確認済みの数 |
